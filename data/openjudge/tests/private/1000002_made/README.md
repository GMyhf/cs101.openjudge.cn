# 第一个 AA 型子串

私有题号 `1000002`，由用户提供的 P1117 [NOI2016]《优秀的拆分》题面简化改编。
目标是返回最早的 AA 型子串起点，下标从 0 开始，没有时返回 -1。
输入保留 T 组形式：1 ≤ T ≤ 10，每个字符串仅含小写字母，1 ≤ n ≤ 2000。
题面总时间限制 2000ms，内存限制 65536kB。

`samplecode.cpp` 保留用户提供的 `firstSquare` 方法，补上读取 T 和输出答案的主程序。
它枚举半长并维护连续相等比较的长度，时间 O(n²)，额外空间 O(1)。
`producecase.py` 使用独立的直接子串比较生成答案，固定随机种子 1000002。

重建数据：

```bash
python3 data/openjudge/tests/private/1000002_made/producecase.py
python3 tools/activate_private_problems.py private 1000002
```

21 组测试文件覆盖样例、单字符、无解、全相同、周期串、仅末尾出现 AA、
长半长对应更早起点、最大 T 和最大 n。通过三元无平方串构造长度 2000 的无解数据，
同时覆盖需要完整扫描的情形。

验证记录见 `collab/private-1000002-review.json`：参考实现实际本地判题 21/21 Accepted；
穷举字母表 abc、长度 1–8 共 9840 个字符串与直接比较核对；
四种错解（按半长找到就返回、1 起始下标、只查相邻字符、漏最后位置）均 Wrong Answer；
生成器重跑后 42 个输入输出文件逐字节一致。
