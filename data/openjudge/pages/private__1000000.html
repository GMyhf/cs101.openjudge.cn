1000000: KMP 字符比较次数（nextval）

总时间限制:
1000ms
内存限制:
65536kB
描述

用 KMP 算法在主串 t 中查找模式串 p 第一次出现的位置，失配时按优化后的 next 数组（nextval）回退。请统计到第一次匹配成功为止，一共做了多少次字符比较。

下标都从 0 开始，m = |p|。

next 数组：next[0] = -1；j ≥ 1 时 next[j] 是 p[0..j-1] 的最长相等真前缀与真后缀的长度。

nextval 数组：nextval[0] = -1；j ≥ 1 时，若 p[j] == p[next[j]]，则 nextval[j] = nextval[next[j]]，否则 nextval[j] = next[j]。

匹配过程（只有 t[i] 与 p[j] 的比较计数，j == -1 时的后移不计数）：

i = j = cnt = 0
while i < |t| and j < m:
    if j == -1:
        i += 1; j = 0; continue
    cnt += 1
    if t[i] == p[j]:
        i += 1; j += 1
    else:
        j = nextval[j]

循环结束时若 j == m，则匹配成功，起始位置为 i - m；否则主串里没有 p。

输入

第一行是模式串 p，第二行是主串 t，均只含大写英文字母，1 <= |p| <= |t| <= 100000。

输出

一行两个整数，用空格隔开：按上面的过程做的字符比较次数 cnt；第一次匹配成功的起始下标，若 t 中没有 p 则输出 -1。

样例输入
BAAABBBAA
BAAABBBCDDDCCHHHHBBBAAABBBAADD
样例输出
31 19
提示

样例的 next 与 nextval：

index012345678
patternBAAABBBAA
next-100001112
nextval-1000-11100

比较过程：

步骤比较内容结果本步次数累计
①T[0..6] 对 p[0..6]7 个都相等77
②T[7]=C 对 p[7]=A≠，j ← nextval[7]=018
③T[7]=C 对 p[0]=B≠，j ← -1，i 后移19
④T[8..16]（D D D C C H H H H）逐个对 p[0]=B都不相等918
⑤T[17]=B 对 p[0]=B=119
⑥T[18]=B 对 p[1]=A≠，j ← nextval[1]=0120
⑦T[18]=B 对 p[0]=B=121
⑧T[19]=B 对 p[1]=A≠，j ← 0122
⑨T[19]=B 对 p[0]=B=123
⑩T[20..27] 对 p[1..8]8 个都相等，匹配成功831

匹配成功的位置是主串下标 19。若改用普通 next 数组，第②步失配后 j 退到 next[7]=1，要多比较一次 C 和 p[1]=A 才退到 0，总共 32 次；nextval 跳过了这次一定失败的比较。
