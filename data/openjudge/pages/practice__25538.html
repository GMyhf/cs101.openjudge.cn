25538:二进制回文的整数

  • 查看
  • 提交
  • 统计
  • 提问
总时间限制:
1000ms
内存限制:
65536kB
描述

二进制是计算技术中广泛采用的一种数制，用0和1两个数码来表示数，如9可以表示为1001，24可以表示为11000。

而在这些数中，存在这样一种特殊情况：1001反转后仍是1001，我们称这个数具有二进制回文的性质，希望你能写一个程序判断输入的数是否具有这个性质。

输入
一个正整数n ( 0 <= n <= 2^32 )
输出
如果它具有二进制回文的性质，那么输出Yes；否则输出No。
样例输入
Sample Input1:
9

Sample Output1:
Yes
样例输出
Sample Input2:
24

Sample Output2:
No

解释：11000(24) != 11(3)
提示
tags: implementation
Python 的内置函数 bin(x) 可以获得 x 的二进制字符串，但是开头会带有多余的 '0b' 需要去除。
