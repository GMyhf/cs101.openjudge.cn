29656:迷宫点灯

  • 查看
  • 提交
  • 统计
  • 提问
总时间限制:
1000ms
内存限制:
65536kB
描述
一座黑暗迷宫形成了一个二叉树，树的每个节点代表一个路口。你拥有一支火把，可以将其安置在迷宫的任意一个路口处，火光可以照亮沿直线传播过程中的所有路口。

如上图所示，左侧表示初始的迷宫，右侧表示在编号为5的路口处放置火把后，火光能够照亮的所有路口。

你的目标是，对于给定的迷宫，找到一个路口放置火把，使得火光照亮的路口数量最多（如果多个位置满足这一条件，选择编号最小的一个）。
输入
输入第一行是一个整数N，表示节点个数，所有节点的编号为1~N，根节点的编号为1。

接下来N行，每行包含两个整数，第i行表示第i个节点的左子节点编号和右子节点编号，以0表示没有对应的子节点。

输入保证形成一颗合理的二叉树。

对于 50% 的测试数据，1 <= N <= 100

其余测试数据，1 <= N <= 100,000
输出
输入两个整数，用空格分隔，表示放置火把的位置和点亮的路口总数。
样例输入
10
2 3
4 5
0 0
0 0
6 7
8 9
0 0
10 0
0 0
0 0
样例输出
5 6
提示
样例与给出的图示一致。
