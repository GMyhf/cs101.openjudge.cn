描述

Background

Alice has been stumped by her big homework recently.

The big homework requires Alice to write an AI to play the Hex Chess game. However, Alice spent a lot of time queuing up to get tickets for some movies, which spent most of her time. With the approaching of big homework deadline, Alice's AI only knew how to play random chess (or perhaps Alice's program had no effect, it's just an Artificial Idiot). In order to finish her big homework, Alice had to seek help from Bob.

Bob is truly a great student. He introduced various solutions such as neural networks, model search, and MCTS to Alice. However, Alice was confused by these complex solutions and only remembered "Estimate the value using the minimum number of chess pieces required to achieve victory"

Feeling sorry to ask Bob again, Alice had to come to you for help. As Alice's good friend, you readily agreed to her.

Introduction to Hex Chess

Hex is a two-player game with a board size of n*n. The two players are red and blue respectively, with alternating red and blue, and red taking the lead.

The red side needs to connect the upper and lower edges with chess pieces, while the blue side needs to connect the left and right edges. The player who completes the above task wins.

Description

Write a program. The input is the situation before you move. Based on the input, calculate the minimum number of chess pieces required for you to achieve victory in this situation. (Not considering the future situation, only considering the current situation. If you can't achive victory, the number is -1.)

Due to Alice's haste, she forgot to tell you the size of the chessboard, you have to write a program that can accommodate different chessboard sizes.

(situation for the example)
输入
The first line is a positive integer n (2 <= n <= 1000), indicating that the size of the chessboard is n*n.

For the next n lines, each line contains n numbers, which can only be 0, 1, or 2, indicating the chess piece of corresponding positions on the chessboard.

0 represents empty, 1 represents red chess piece, and 2 represents blue chess piece.

Ensuring that the number of red and blue pieces is equal, or one more red than blue pieces.
输出
1 line in total, with 1 integer, which is the minimum number of pieces required for your side to achieve victory in this situation.
样例输入
5
0 1 0 0 1
2 1 2 2 0
1 1 2 2 0
2 0 1 0 1
0 0 0 0 0
样例输出
4
提示
In the example, your side is blue, the the minimum number of pieces required for blue is 4(as figure above).
