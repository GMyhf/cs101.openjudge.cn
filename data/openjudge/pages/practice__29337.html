29337:目标和

总时间限制:
1000ms
单个测试点时间限制:
1000ms
内存限制:
65536kB
描述

给你一个非负整数数组 nums 和一个整数 target 。

向数组中的每个整数前添加 '+' 或 '-' ，然后串联起所有整数，可以构造一个 表达式 ：

  • 例如，nums = [2, 1] ，可以在 2 之前添加 '+' ，在 1 之前添加 '-' ，然后串联起来得到表达式 "+2-1" 。

求可以通过上述方法构造的、运算结果等于 target 的不同 表达式 的数目。

 

  • 1 <= nums.length <= 20

  • 0 <= nums[i] <= 1000

  • 0 <= sum(nums[i]) <= 1000

  • -1000 <= target <= 1000

输入
第一行为非负整数数组 nums ，其中每一个数用空格分隔。

第二行为整数 target 。
输出
一个整数，表示不同 表达式 的数目。
样例输入
1 1 1 1 1
3
样例输出
5
提示
dp, 回溯；另一组样例：输入两行 1 和 1，输出 1。
