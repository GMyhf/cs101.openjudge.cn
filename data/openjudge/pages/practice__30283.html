30283:骑士大游历

总时间限制:
8000ms
单个测试点时间限制:
4000ms
内存限制:
256000kB
描述

“骑士游历”问题是一道经典的问题：从1000*1000棋盘上的一点 (x1, y1) 出发，到另一点 (x2, y2) 的最短距离是多少？当然，骑士只能按照“日”字形走法来前进。
如何快速地得到这个问题的解？我们需要你算出这样的问题。

输入
第一行是测试数据的数目t（1 <= t <= 20）。
以下每行均包含四个整数x1 y1 x2 和y2，以空格分开，前两个是起点坐标，后两个是终点坐标。
0 <= x1, y1, x2, y2 <= 999。
输出
对应输入的每组数据，输出相应的最短距离。
样例输入
4
0 0 999 999
0 0 1 2
0 0 2 2
500 500 505 505
样例输出
666
1
4
4
提示
双向 BFS (Bi-directional BFS)。如是Python代码，建议PyPy3提交。

注意：PyPy3兼容性可能不如Python3稳定，尤其是在处理较为简单的题目时可能会遇到问题。通常优先使用Python3提交进行尝试，确保代码能够顺利通过测试。
