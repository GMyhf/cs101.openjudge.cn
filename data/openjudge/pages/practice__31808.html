描述

故事背景

宇宙是一个充满未知和危险的黑暗森林。在这个宇宙中，文明之间的相互发现往往意味着生存的威胁。而在遥远的宇宙深处，存在着一个高度发达的观测者文明。这个文明拥有先进的科技，能够精确地观测和记录其他文明在宇宙中的坐标。他们相信，通过分析这些坐标，可以预测不同文明之间的潜在冲突。

观测者文明的科学家们发现了一个有趣的现象：如果两个文明在二维平面上的连线斜率的绝对值不大于 1，那么这两个文明之间的互相发现从而产生冲突的可能性会大大增加。这个发现对于观测者文明来说至关重要，因为它可以帮助他们更好地理解和预测宇宙中的文明动态。

为了进一步研究这一现象，观测者文明的科学家们需要一个算法来快速计算出在给定的二维平面上，满足这一条件的文明对数。现在，作为观测者文明的一名编程专家，你的任务是开发这个算法，帮助科学家们更好地理解和预测宇宙中的文明动态。

题目描述

给定二维平面上的 n 个文明坐标，每个文明用一对整数坐标 (x_i, y_i) 表示，其中 i 从 1 到 n。你需要编写一个程序，计算并输出所有满足以下条件的文明对 (i, j) 的数量：文明 i 和文明 j 之间的连线斜率的绝对值不大于 1。即对于任意两个不同的文明 (x_i, y_i) 和 (x_j, y_j)，满足 |(y_i - y_j) / (x_i - x_j)| ≤ 1。

输入
第一行包含一个整数 n ，表示文明的数量。
接下来的 n 行，每行包含两个整数 x_i 和 y_i，表示第 i 个文明的坐标。
输出
输出一个整数，表示满足条件的文明对数量。
样例输入
样例输入1：
4
0 0
1 1
1 0
0 1

样例输入2：
4
0 0
0 0
1 1
1 2
样例输出
样例输出1：
4

样例输出2：
3
提示
两个文明二维坐标的重合情况（即 x_i = x_j, y_i = y_j）也视作满足条件。
斜率不存在的情况，（即 x_i = x_j, y_i ≠ y_j），视作不满足条件。
样例解释 1：在给定的四个文明中，满足条件的文明对有：(0,0) 和 (1,1)，(0,0) 和 (1,0)，(1,1) 和 (0,1)，(1,0) 和 (0,1)。
样例解释 2：在给定的四个文明中，满足条件的文明对有：(0,0) 和 (0,0)，(0,0) 和 (1,1)，(0,0) 和 (1,1)。

对于 70% 的数据，1 ≤ n ≤ 1000；
对于 100% 的数据，1 ≤ n ≤ 2 * 10^5，0 ≤ x_i, y_i ≤ 10^9。
