描述

本题需要你编写一段程序，从交互库猜出一个整数x。

你可以调用交互库中的query(i)最多15次，

它接收一个[0,1000]内的整数i（只接受范围内的int，请不要越界调用），

返回一个整数提示用户i与x的大小关系（i>x→1；i=x→0；i<x→-1）；

请在query返回0（猜对）之后直接结束你的程序，不要再次调用query。

提示：你不需要读懂交互库代码，你可以跳过下面的代码和技术描述，仅查阅“样例输出”部分的示例代码，然后直接开始做题。

补充提示：只需要交你的调用程序即可，不要在提交区把交互库再copy一遍。

import random, time, sys
ans = random.randint(0, 1000)
query = lambda i: 0 if i == ans else (1 if i > ans else -1)
io1 = int(input())
io2 = int(input())
toexpr = lambda x: ' + '.join(f"((lambda: 1)() << ({' + '.join(['(lambda: 1)()'] * i)} + 0))" for i in range(10) if x & (1 << i)) + '+ 0'
cnt = 0
exec(f'''def query(i):
    global cnt
    assert ''.__class__.__class__(''.join) == ''.__class__.__class__(sys.__stdout__.write)
    assert ''.__class__.__class__(''.__eq__) == ''.__class__.__class__(sys.__stdout__.write.__self__.__repr__)
    assert sys.__stdout__.write.__self__.__repr__() == "<_io.TextIOWrapper name='<stdout>' mode='w' encoding='utf-8'>"
    sys.__stdout__.write(''.__class__({toexpr(io1)}) + (10).to_bytes(1, 'big').decode())
    assert ''.__class__.__class__(i) == (0).__class__
    assert 0 <= i <= 1000
    assert ''.__class__.__class__(cnt) == (0).__class__
    assert cnt < 15
    cnt += 1
    if i == {toexpr(ans)}:
        while cnt < 15:
            cnt += 1
            sys.__stdout__.write(''.__class__({toexpr(io1)}) + (10).to_bytes(1, 'big').decode())
        sys.__stdout__.write(''.__class__({toexpr(io2)}))
        return 0
    return 1 if i > {toexpr(ans)} else -1''')
time.sleep(random.random() * 0.05)
random.seed(0)
del ans, io1, io2

输入

		
你不需要也不应该从stdin获取任何信息或向stdout输出任何内容；
事实上，预设代码从stdin里读取题目信息后stdin将被清空；
预设代码会根据query的调用次数和结果判定正确，
如果你的程序正确，测评代码将向stdout输出若干非空字符串，
该字符串你无法直接读取，向stdout输出多余内容将导致WA。

		
输出

		
交互库自适应，代码已公开，
你可以尝试通过破坏交互库获取AC（包括不进行正常交互即获得敏感数据和成功超限调用交互库），计为有效AC代码。

		
样例输入

		
#假设猜测的数是3，则可能会发生的过程：
#调用query(0)，返回-1
#调用query(1)，返回-1
#调用query(2)，返回-1
#调用query(3)，返回0
#结束程序

		
样例输出

    if query(i) == 0:
        break
