19930:寻宝

  • 查看
  • 提交
  • 统计
  • 提问
总时间限制:
1000ms
内存限制:
65536kB
描述

Billy获得了一张藏宝图，图上标记了普通点（0），藏宝点（1）和陷阱（2）。按照藏宝图，Billy只能上下左右移动，每次移动一格，且途中不能经过陷阱。现在Billy从藏宝图的左上角出发，请问他是否能到达藏宝点？如果能，所需最短步数为多少？

输入
第一行为两个整数m,n，分别表示藏宝图的行数和列数。(m<=50,n<=50)
此后m行，每行n个整数（0，1，2），表示藏宝图的内容。
输出
如果不能到达，输出‘NO’。
如果能到达，输出所需的最短步数（一个整数）。
样例输入
样例输入1：
3 4
0 0 2 0
0 2 1 0
0 0 0 0

样例输出1：
5
样例输出
样例输入2：
2 2
0 2
2 1

样例输出2:
NO
提示
每张藏宝图有且仅有一个藏宝点。
输入保证左上角（起点）不是陷阱。
