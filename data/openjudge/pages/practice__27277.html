27277:凑硬币

  • 查看
  • 提交
  • 统计
  • 提问
总时间限制:
1000ms
内存限制:
65536kB
描述

小北无聊的时候发明了一个凑硬币的游戏：告诉你几种硬币的面额，以及想要凑成的金额，问最少能用几个硬币凑出这个金额。现在，小北想邀请你和他一起玩这个新游戏，但你想到这学期上了计算概论B课程，打算写一个程序陪小北玩，这样就能省下时间复习期末考试了。

你可以认为每种硬币的数量是无限的。

输入
第一行为整数数组 coins，表示硬币的面额（注意：面额可能不是有序的）。

第二行为整数 amount ，表示想要凑成的金额。

1 <= coins.length <= 12
1 <= coins[i] <= 2^31 - 1
0 <= amount <= 10^4
输出
一个数，表示所需最少的硬币个数。如果没有任何一种硬币组合能组成总金额，返回 -1 。
样例输入
Sample1 Input:
1 2 5
11

Sample1 Output:
3
#11=5+5+1
样例输出
Sample2 Input:
1
0

Sample2 Output:
0

Sample3 Input:
2
3

Sample3 Output:
-1
提示
tag: dp. 注：本题greedy, dfs, bfs可能也可以解决，取决于时间复杂度的限制
