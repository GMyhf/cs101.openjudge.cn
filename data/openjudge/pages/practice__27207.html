27207:铑纳米管

总时间限制:
1000ms
单个测试点时间限制:
1000ms
内存限制:
65536kB
描述

铑可以形成一种二维聚合单质，我们管它叫聚铑。聚铑平面可以剪切并在空间中卷曲，形成铑纳米管。铑纳米管是很卷的聚铑。HYX是经典的铑纳米管。
现在HYX正在做晶化实验，实验内容是有机官能团修饰的铑纳米管偶极的纯液相生长与拼装。HYX可以制备n(1<=n<=10000)种铑纳米管。每种铑纳米管都有k(1 <=k<= 100)种配方。
对于每种配方，其摩尔制备用时为t(0 <= t <= 0000)，所需要的前体摩尔数量为x(0 <= x <= 10000)。可能有多摩尔同种前体。
特别地，x=0表示不用前体就可以直接制备。同时，铑纳米管的制备是化合反应，所以不会出现循环制备的问题。
由于HYX自己就是铑纳米管，他的所有实验操作都能做到产率100%。但是他一次只能制备1摩尔的铑纳米管。
由于实验课老师正在巡逻，HYX需要尽快完成目标（0号）铑纳米管的制备。问他制备目标铑纳米管的最短时间是多少。

输入
第一行一个整数n (1 <= n <= 10000)，表示需要制备的铑纳米管的数量。
其后每组数据有(2k+1)行，第一行一个整数 k (1 <= k <= 100)，表示配方数。
其后2k行，每两行是一种铑纳米管，编号从0到n-1。
第一行两个整数：t( 0 <= t <= 10000)，表示摩尔制备用时；x (0 <= x <=1 0000)，表示前体摩尔数，x=0时表示制备该铑纳米管不需要前体。
第二行x个整数，表示前体的编号。x=0时输入一个空行。
输出
一个整数，表示制备目标铑纳米管的最短时间。
样例输入
3
3
1 3
1 1 2
2 2
2 2
9 0

2
4 0

1 1
2
1
1 0
样例输出
4
