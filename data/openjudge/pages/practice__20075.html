20075:寻宝2.0.v0.3

  • 查看
  • 提交
  • 统计
  • 提问
总时间限制:
1000ms
内存限制:
65536kB
描述

可爱的Billy又获得了一张藏宝图，图上标记了普通点（0），藏宝点（1）和陷阱（2）。按照藏宝图，Billy只能上下左右移动，每次移动一格，且途中不能经过陷阱。现在Billy从藏宝图的任意点出发（如果足够倒霉，脚下可以是陷阱点），请问他是否能到达藏宝点？如果能，所需最短步数为多少？
注：以左上角为坐标原点，向右为x轴正方向，向下为y轴正方向

输入
第一行为三个整数m,n,p, 分别表示藏宝图的行数和列数、Billy可能的出发点坐标的个数。(m<=100,n<=100,0此后m行，每行n个整数（0，1，2），表示藏宝图的内容。
最后p行，每一行都是Billy可能的一个出发点坐标，第一个数是横坐标，第二个是纵坐标，中间用空格分开。保证坐标在地图上。
输出
如果不能到达，输出‘NO’。
如果能到达，输出所需的最短步数（一个整数）。
样例输入
Sample1 input:
3 4 1
0 0 2 0
0 2 1 0
0 0 0 0
1 1

Sample1 output:
5
样例输出
Sample2 input:
5 5 5
0 0 2 2 0
2 0 0 0 2
0 0 2 0 2
0 2 2 1 2
0 0 2 2 2
1 1
2 1
1 5
4 4
5 1

Sample2 output:
6
5
8
0
NO
