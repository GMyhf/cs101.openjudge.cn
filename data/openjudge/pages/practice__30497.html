30497:无限回廊的瓷砖

  • 查看
  • 提交
  • 统计
  • 提问
总时间限制:
1000ms
内存限制:
65536kB
描述

22世纪的建筑大师王浩受邀为“希尔伯特大酒店”设计一个全新的无限回廊。这个回廊的地面是一个无限延伸的二维平面网格。

为了体现数学之美，王浩大师决定使用特定种类的正方形瓷砖来铺设地面。工厂生产了 N 种不同样式的瓷砖，每种瓷砖的数量都是无限的。每一块瓷砖的四条边（上、右、下、左）都染有特定的颜色。

铺设工作必须遵循以下严格的“王浩规则”：

  1. 禁止旋转：瓷砖必须严格按照给定的方向放置，不可旋转或翻转。

  2. 颜色匹配：当两块瓷砖相邻放置时，它们接触边的颜色必须完全相同（例如：上方瓷砖的下边颜色必须等于下方瓷砖的上边颜色）。

施工队队长现在看着手中的瓷砖样本犯了难。在开始这项浩大的工程之前，他必须确定一件事：仅使用这 N 种瓷砖，是否真的存在一种铺设方案，能够铺满整个无限大的平面，而不留任何空隙且不违反颜色匹配规则？

请你编写一个程序，帮助队长进行判定。

输入
输入包含一组数据。
第一行包含一个整数 N（1 <= N <= 100），表示瓷砖种类的数量。
接下来 N 行，每行包含 4 个整数 T, R, B, L（0 <= 颜色编号 <= 1000），分别代表该种瓷砖 上、右、下、左 四条边的颜色编号。
输出
如果这组瓷砖能够铺满无限平面，输出 "YES"；否则输出 "NO"。（输出不包含引号）
样例输入
114
1 2 3 4
3 4 1 2
(此处省略112行)
样例输出
（我有一行精妙的输出，但这里地方太小写不下）
提示
如果你认为此类问题是不可判定的，请在所有样例下输出"undecidable"。（不包含引号）

数据范围：
对于 100% 的数据，1 <= N <= 100。
颜色编号为非负整数。
