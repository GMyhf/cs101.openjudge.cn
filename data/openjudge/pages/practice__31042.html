31042:简化版 Git Diff 引擎

1000ms
内存限制:
1000kB
描述

在版本控制系统 Git 中，当运行 git diff 查看两个版本的代码差异时，其底层核心使用的是最长公共子序列（LCS）算法。Git 会把文件的每一行作为一个基本单元（相当于字符串中的一个字符），寻找两个文件之间最长的相同行序列。没有被包含在 LCS 中的行，就是被“删除”或“新增”的内容。

【输出唯一性限制】

最长公共子序列（LCS）的匹配结果可能不唯一。为了确保评测系统能进行精确的代码比对，在工程实践中我们遵循以下“状态序列最小化”的平局打破规则：

我们定义每种行状态的权重分值如下：

  • 空格 ' '（未修改的共同行） = 0

  • 减号 '-'（删去的行） = 1

  • 加号 '+'（新加的行） = 2

当存在多种等长的 LCS 匹配方案时，你所生成的最终行状态序列，其对应的权重分值按从上到下的顺序组合，必须是所有合法方案中字典序（分值序列）最小的那一个。

(提示：此规则天然确保了在同一修改块内，删除行 '-' 会集中排在新增行 '+' 的前面；且相同的代码行会优先在靠前的位置进行匹配。)

输入
文件的不同两个版本。
第一行：一个整数 N，代表第一个文件（旧版本）的行数。接下来 N 行：每行代表旧版本文件的文本内容。
紧接着的一行：一个整数 M，代表第二个文件（新版本）的行数。接下来 M 行：每行代表新版本文件的文本内容。比如：
N
[第 1 版本的 N 行文本]
M
[第 2 版本的 M 行文本]
输出
在新文件的基础上，显示相对于旧文件的修改，在每一行行首添加状态字符：
加号'+'表示新加的行；
减号'-'表示删去的行；
空格' '表示没有修改的行。
样例输入
3
def main():
    print('Hello')
    return True
4
def main():
    # 打印问候
    print('Hello World')
    return True
样例输出
 def main():
-    print('Hello')
+    # 打印问候
+    print('Hello World')
     return True
