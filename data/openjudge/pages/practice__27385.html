27385:最小值

  • 查看
  • 提交
  • 统计
  • 提问
总时间限制:
10000ms
单个测试点时间限制:
1000ms
内存限制:
262144kB
描述

给定一个长度为 2k 的数组：a0, a1, ... a2^k-1，你要执行 q 次操作，每次操作为以下两种之一：

1 l r：从 [l, r] 中选取两个整数 x 和 y（x可以等于y），使得ax * ay最小。输出这个最小值。

2 x y：将 ax 的值修改为 y。

输入
第一行包含一个整数k。
第二行包含 2k 个整数，代表 a0, a1, ..., a2k-1，注意数组下标从 0 开始。
第三行包含一个整数 q。
以下 q 行每行包含 3 个整数，代表一个操作。
输出
对于每个1类操作，输出一个整数代表最小值。
样例输入
3
1 1 2 2 1 1 2 2
5
1 0 7
1 1 2
2 1 2
2 2 2
1 1 2
样例输出
1
1
4
提示
对于60%的数据，0 ≤ k ≤ 13。
对于100%的数据，0 ≤ k ≤ 17, 1 ≤ q < 2k, -2k ≤ ai,y ≤ 2k, 0 ≤ l ≤ r < 2k, 0 ≤ x < 2k。
