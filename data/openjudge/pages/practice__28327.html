28327:相遇地点

  • 查看
  • 提交
  • 统计
  • 提问
总时间限制:
10000ms
单个测试点时间限制:
1000ms
内存限制:
262144kB
描述

A国有 N 个城市和 N-1 条道路。城市编号从 1 到 N，第 i 条道路连接城市 ai 和 bi，所有道路双向通行，且长度相等。任意两个城市间都能通过这些道路直接或间接相连。

请你回答 Q 个问题，每个问题包含两个整数 ci 和 di，请回答：

- 小明从城市 ci 出发，小天从城市 di 出发，它们同时以相同的速度移动，小明的目标是城市 di，小天的目标是城市 ci。请计算它们相遇地点。如果他们相遇在某个城市，输出 "City x"；如果相遇在某条道路中间，输出 "Road x y"。假设经过城市的时间忽略不计（即只有在道路上会消耗时间）。

输入
第一行一个整数 N (2 ≤ N ≤ 2000)。
接下去 N-1 行，每行两个整数 ai, bi (1 ≤ ai < bi ≤ N) 表示一条道路。
接着一行包含一个整数 Q (1 ≤ Q ≤ 2000)。
接下去 Q 行，每行两个整数 ci, di (1 ≤ ci, di ≤ N, ci ≠ di) 表示一个问题。
输出
共 Q 行，每行表示一个答案，用 "City x" 表示恰好在城市 x 相遇；用 "Road x y" 表示在连接 x 和 y 的道路上相遇，输出时要求 x < y。

对于 30% 的数据，N,Q ≤ 10;
对于全部数据，2 ≤ N ≤ 2000, 1 ≤ Q ≤ 2000。
