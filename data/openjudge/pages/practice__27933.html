27933:Okabe and Boxes

  • 查看
  • 提交
  • 统计
  • 提问
总时间限制:
1000ms
内存限制:
65536kB
描述

Okabe和超级黑客Daru正在堆叠和移除盒子。有n个盒子编号为1到n。最初，栈上没有盒子。

作为一个控制狂，Okabe给了Daru 2n个命令：n个命令让他将某一个盒子加入栈中，n个命令让他弹出栈顶。Okabe希望弹出栈顶的盒子顺序是从1到n。当然，这意味着Daru可能无法执行Okabe的一些移除命令，因为所需的盒子不在栈顶。

Daru为了执行Okabe的命令，可以等到Okabe看向别处时，以任何他想要的方式重新排列栈中的盒子。他可以在两个命令之间任何时间点做这件事，但他不能在做这件事的同时添加或移除盒子。 告诉Daru他需要重新排列盒子的最少次数，这样他就可以成功地完成Okabe的所有命令。命令保证每个盒子都在需要移除之前添加。

输入
输入的第一行包含整数 n (1≤ n ≤ 10^4)，表示盒子的数量。

接下来的2n行输入都以字符串“add”或“remove”开头。如果该行以“add”开头，则后面跟着一个整数 x (1≤ x ≤ n)，表示Daru应该将编号为 x 的盒子添加到堆栈顶部。

输入保证恰好有 n 行“add”和 n 行“remove”，“add”的盒子编号为1-n且各不相同，保证盒子总是在被要求移除之前被添加。
输出
打印Daru需要重新排列盒子的最少次数，以成功完成Okabe的所有命令。
样例输入
sample1 input:
3
add 1
remove
add 2
add 3
remove
remove

sample1 output:
1

# Daru需要在第3个盒子添加到栈中后，重新排列盒子。
样例输出
sample2 input:
7
add 3
add 2
add 1
remove
add 4
remove
remove
remove
add 6
add 7
add 5
remove
remove
remove

sample2 output:
2

# Daru需要在4号盒子和7号盒子添加到栈中后，重新排列盒子。
