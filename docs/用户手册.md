# CS101 本机判题 · 使用手册

面向学生。管理相关内容见 [管理员手册](管理员手册.md)。

## 1. 账号

### 注册

打开 `/register/`，需要填：

| 项 | 要求 |
| --- | --- |
| 邮箱 | 用于激活与找回密码 |
| 用户名 | 2–32 个字符，只能是字母、数字、下划线、中文、短横线 |
| 密码 | 至少 8 位 |
| 人机验证 | 一道加法题 |

提交后系统会发一封激活邮件，**链接 24 小时内有效**，点击后账号才能登录。
没收到就先看垃圾箱；仍然没有，找管理员。

### 登录

`/auth/login/`。**用户名不区分大小写**，`ZhangSan` 和 `zhangsan` 是同一个账号。

> 连续输错 **10 次**会锁定 **15 分钟**，锁定期间即使密码正确也会被拒。
> 锁定是按用户名算的，换台机器不会解锁 —— 等 15 分钟，或找管理员。

### 忘记密码

`/auth/forgot/` 填注册邮箱，会收到重置链接，**30 分钟内有效**。

无论邮箱是否注册过，页面都显示同一句提示 —— 这是有意的，避免别人用它试探谁注册过。

### 修改密码

登录后进 `/account/`。

> **改密码会把你在其它地方的登录状态全部踢掉**（当前这个浏览器除外）。
> 如果怀疑账号被盗，改密码就是有效的补救手段。

会话本身最长保持 **14 天**，之后需要重新登录。

## 2. 找题目

- **首页 `/`** —— 每个题库随机展示 5 道可直接判题的题目，顶部搜索框可按题号或标题过滤。
- **题库目录 `/problems/`** —— 全部题目，可按题库筛选、搜索，并标注每道题**有没有测试数据**。

**没有测试数据的题目提交后会返回 `No Test Data`** —— 不是你的代码有问题，是这道题还没配数据。
按 `data/openjudge/catalog.json` 现场核算（2026-08-27），当前有 1,851 条目录记录，
其中 1,833 条有测试数据。目录记录包含不同题库/别名，因此不等同于唯一题号数量。

## 3. 提交页

地址是 `/题库/题号/`，例如 `/practice/02942/`。整页不滚动，分成几块独立面板。

```
┌──────────────────────────────────────────────┐
│ CS101  02942 · 题库    目录 记录 说明  ☾ 账号 │
├─────────────────┬────────────────────────────┤
│ 描述|提交记录|统计│ 代码   Python3 ▾  A- A+ 清空│
│                 │  1  n = int(input())       │
│ 总时间 1000ms    │  2  ...                    │
│ 内存 65536kB     │                            │
│                 ├════════════ 可上下拖 ══════┤
│ 描述            │ 判题结果 | 样例             │
│ 输入 / 输出      │ ✓ Accepted 12ms 3.2MB      │
│ 样例输入/输出    ├────────────────────────────┤
│                 │        [运行样例] [提交并判题]│
└─────────────────┴────────────────────────────┘
        ↑ 中间竖线可左右拖
```

### 左侧三个标签

- **题目描述** —— 题面。右上角「复制 Markdown」把整道题复制成 Markdown，方便贴到笔记里。
- **提交记录** —— 你在这道题的提交历史；「看全部」可切换成所有人的记录。
- **统计** —— 这道题的提交次数、通过率、提交/通过人数。

### 代码编辑器

无需安装任何东西，直接在网页里写：

- 语法高亮、行号
- **Tab** 缩进 4 个空格
- 回车**自动缩进**（Python 的 `:` 和 C 系的 `{` 之后多缩一级）
- 括号、引号**自动配对**，光标在空的一对中间按退格会一次删掉两个
- 光标停在括号上会高亮显示配对的另一半
- `A-` / `A+` 调字号，「清空」清空代码

### 布局与主题

- 中间竖线**左右拖**调节题面与编辑器宽度；结果面板上方的横线**上下拖**调节高度。
  两个位置都记在本浏览器里，下次打开还在。也可以用键盘：Tab 聚焦到分隔条后按方向键。
- 顶栏 **☾ 按钮**切换深色/浅色，默认跟随系统设置。

## 4. 运行样例 vs 提交并判题

这是两件不同的事：

|  | 运行样例 | 提交并判题 |
| --- | --- | --- |
| 跑什么数据 | 题面里的样例，**输入框可以改** | 全部测试数据 |
| 会不会比对 | 只提示与样例是否一致 | 严格判定 |
| 进不进提交记录 | **不进**，不影响统计 | 进，计入通过率 |
| 用途 | 调试 | 正式交题 |

有多组样例时，「样例」标签页上方会出现「样例 1 / 样例 2 …」切换。

> **建议**：先用「运行样例」调通，再「提交并判题」。这样既快，也不会在提交记录里留下一串失败。

## 5. 判题结果怎么读

| 结果 | 含义 | 怎么办 |
| --- | --- | --- |
| **Accepted** | 全部测试点通过 | — |
| **Wrong Answer** | 输出不对。会告诉你**错在第几组**，以及期望/实际的 token 数量 | token 数差很多通常是格式或循环次数问题 |
| **Time Limit Exceeded** | 超时 | 换更优的算法；Python 可以试试选 PyPy3 |
| **Runtime Error** | 运行时崩溃，会附上错误输出 | 看报错，多半是越界、除零、递归过深 |
| **Compile Error** | 编译/语法错误，会附上编译器信息 | 按提示改 |
| **Output Limit Exceeded** | 单组输出超过 2 MB | 通常是死循环里一直打印 |
| **No Test Data** | 这道题还没有测试数据 | 换一道题 |
| **Rate Limited** | 提交太频繁 | 等提示的秒数 |

### 输出比对规则（重要）

判题按 **token** 比对：把你的输出和标准答案都按空白切分，然后逐个比较。

- ✅ **空格数量、换行位置、行尾空白都不影响结果**
- ❌ token 的**内容和顺序**必须完全一致

所以 `print(a, b)` 和 `print(a); print(b)` 判定相同；但多打印一个字、少一个数、顺序反了都会 WA。

> ⚠️ 一个已知例外：如果题目用**行首空格**表达含义（比如输出带缩进的结构），
> token 比对看不出缩进差异，本站可能判过而平台判错。这类题以平台为准。

## 6. 运行限制

### 时间

限时按**题面给的时间**乘以**语言倍率**：

| 语言 | 时间倍率 | 说明 |
| --- | --- | --- |
| Python3 | ×10 | |
| PyPy3 | ×3 | 算法相同时通常比 Python3 快很多 |
| C / C++ / Swift / Objective-C | ×1 | 题面限时按这一档定 |
| C# / F# / VB.NET | ×2 | 内存也是别人的 2 倍 |

- 单组测试的 CPU 时间夹在 **4 ～ 20 秒**之间
- 整次提交最长 **300 秒**，超了会以 TLE 收尾

### 其它

| 项 | 限制 |
| --- | --- |
| 内存 | 768 MB（C#/F#/VB.NET 为 1536 MB） |
| 单组输出 | 2 MB |
| 代码长度 | 512 KiB |
| 运行样例的输入 | 64 KiB |

### 频次

| 操作 | 默认额度 |
| --- | --- |
| 运行样例 | 5 分钟内 30 次 |
| 提交判题 | 10 分钟内 20 次 |

同一时刻**只能有一次判题在跑**，上一次没结束时再点会提示「上一次判题还在跑」。

> 这些数字管理员可以调整，考试期间可能与平时不同。

## 7. 提交记录

`/history/` 是你的全部提交记录，可以：

- 按题号或结果筛选
- 调整显示条数（50 / 200 / 500）
- 展开查看当时提交的代码和判题详情

**只有你自己和管理员能看到你提交的代码**；别人在题目页的「看全部」里只能看到结果，看不到源码。

## 8. 常见问题

**本站过了，平台没过？**
最常见是**超时**（本站限时可能比平台宽松）和上面提到的**行首空格**。也可能是本站的数据比平台弱。

**为什么我改对了还是 WA？**
先看「错在第几组」和 token 数量对不对。token 数对但内容错，通常是边界情况；token 数不对，通常是输出格式或循环次数。

**Python 超时了怎么办？**
先想算法。确实是常数问题的话，语言选 **PyPy3** —— 同一份代码倍率从 ×10 变成 ×3。

**代码写到一半刷新就没了？**
编辑器内容不会自动保存，重要代码请自己留一份。

**登录不上？**
确认是不是连续输错 10 次被锁了 15 分钟。忘记密码走 `/auth/forgot/`。
